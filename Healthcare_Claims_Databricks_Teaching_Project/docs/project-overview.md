# Project Overview

## Business Problem

A healthcare organization has claims data in a legacy relational database. The organization wants a modern cloud data-processing pipeline.

## Solution

The teaching project demonstrates:

SQL Server-style source
→ SQL migration
→ Databricks SQL / PySpark
→ validation
→ curated provider summary
→ scheduled workflow

## Why this project is useful

The project is intentionally small. A student can understand the complete pipeline without being overwhelmed by enterprise infrastructure.

At the same time, it introduces the same concepts used in larger projects:

- Legacy modernization
- SQL conversion
- ETL
- Spark
- Data quality
- Governance
- Orchestration
- Version control
